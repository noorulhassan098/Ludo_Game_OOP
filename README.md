Ludo Game - Java OOP Project

A fully interactive Ludo Game developed in Java using Swing and AWT for the graphical user interface. The project implements the traditional Ludo board game with a visually appealing GUI, dice rolling functionality, player turns, token movement, and win condition management. It is designed following Object-Oriented Programming (OOP) principles to ensure modularity, reusability, and maintainability of code.

Features
Interactive graphical user interface using Java Swing & AWT
Multiplayer gameplay support
Dice rolling mechanism
Real-time token movement on the board
Turn-based player management
Winner detection system
Modular OOP-based architecture
Event handling and GUI components implementation

Java
Java Swing
